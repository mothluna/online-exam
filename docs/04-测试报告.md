## 一、测试环境与方法

| 项 | 取值 |
|---|---|
| 操作系统 | Windows 11（amd64） |
| JDK | Temurin 17.0.2 |
| 数据库 | MySQL 8.0.36（容器 `oes-mysql`），测试库 `oes_test`（Flyway 自动建表） |
| 缓存 | Redis 7.2（容器 `oes-redis`），测试使用 **DB 15** 与开发会话隔离 |
| 测试框架 | JUnit 5 + Spring Boot Test + MockMvc |
| 数据隔离 | `@Transactional` 每个用例回滚；题干/标题带 UUID，重复执行不冲突 |

**为什么不用 Testcontainers**：本机 Docker 只能手动启动、镜像源不稳定（见 D-001 / D-002），
用 Testcontainers 拉镜像会让测试在无网/无 Docker 时整体失败。
当前方案连真实 MySQL/Redis，只要求容器已启动，结果同样可信；后续需要 CI 时再切换。

## 二、单元测试

### 2.1 判分规则 `ScoreRulesTest`（22 条，全部通过）

| 类型 | 覆盖点 |
|---|---|
| 多选 | 全对满分 / 少选按比例向下取整 / 含错选 0 分 / 未作答 0 分 / 奇数分值取整 |
| 单选 · 判断 | 全等得分、未作答 0、半分题精确得 50 |
| 填空 | 多空按空计分、`\|` 分隔的"或"答案、末空不吃余数（对称性） |
| 简答 | 关键词命中计分、最小字数门槛、得分 clamp 到 `[0, 满分]` |

### 2.2 题干归一化 `StemNormalizerTest`（8 条，全部通过）

全角问号 + 首尾空格 → 同一指纹；连续空白压缩；英文小写、中文不受影响；
中英文标点统一；去首尾标点；空输入稳定；不同内容不同指纹；SHA-256 为 64 位小写十六进制。

### 2.3 分值换算 `ScoreUtilTest`（5 条，全部通过）

元 ↔ 0.01 分精确换算；三位小数拒绝；空值拒绝；`0.10 + 0.20 == 0.30` 无浮点误差。
